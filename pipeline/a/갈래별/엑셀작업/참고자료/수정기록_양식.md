# 참고자료 — 수정 기록 파일 양식 (엑셀작업 갈래)

> 출력 A 가 작업본과 함께 남기는 수정 기록 파일의 꼴. 규칙은 `규칙.md` §7 (D-59 G-2~G-6 · D-60 G-10 · D-61 G-14 · D-70). 이름·자리는 레이아웃 문서 §8 이 정한다 — 기본 `output/T{N}_<작업명>/<작업본 이름>_수정기록.md`.
> 한 파일에 판본 절을 **덧붙인다.** 이전 판본 절은 지우거나 고치지 않는다.

---

```markdown
# 수정 기록 — <작업본 파일명>

| 항목 | 값 |
|---|---|
| 작업본 | `output/T{N}_<작업명>/<파일명>.xlsx` |
| 바탕 (원래 값의 출처) | `input/…` · SHA-256 (바탕 없음이면 "R1 판 — `<작업본 이름>.preR2.bak` · SHA-256. R1 은 기록 안 함, R2 부터 기록하고 원래 값은 R3 이후에도 R1 판 값") |
| 표시 색 | `FF……` (레이아웃 문서 §8) |
| 승인된 레이아웃 | `log/T{N}_<작업명>/설계명세.md` · SHA-256 |

## R<M> — YYYY-MM-DD

| 항목 | 값 |
|---|---|
| 이 판 작업본 SHA-256 · 크기 | |
| 편집 직전 백업 | `<작업본 이름>.pre<단계>.bak` · SHA-256 (단계가 여럿이면 줄을 더한다) |
| 이 절의 줄 수 · 펼친 셀 수 | |

### 셀
| # | 시트 | 셀 (또는 범위) | 원래 값 (원본) | 고친 값 | 근거 | 레이아웃 결정 |
|---|---|---|---|---|---|---|

### 도형 (색 표시 없이 여기에만)
| # | 시트 | 도형 이름 / id | 바꾼 속성 | 전 | 후 | 근거 | 레이아웃 결정 |
|---|---|---|---|---|---|---|---|

### 값 외 변경 (서식 · 열 너비 · 행 높이 · 인쇄 설정 · 시트 순서 · 병합 · 행·열 삽입/삭제)
| # | 시트 | 위치 | 무엇이 | 전 → 후 | 근거 |
|---|---|---|---|---|---|
```

## 칸을 채우는 법

| 칸 | 어떻게 |
|---|---|
| 셀 (또는 범위) | 원래 값이 있던 칸은 **셀 하나에 한 줄.** 새로 채운 칸 · 새 행 · 새 열만 범위 한 줄(`C5:C40`)로 묶을 수 있다 (G-14) |
| 원래 값 (원본) | **원본(바탕) 셀의 값**을 글자 그대로 (줄바꿈 포함). 어느 판본 절이든 같다 (G-2 · G-10). 바탕 없음(신규 작성)이면 원본 = **R1 판** — R3 이후 절에서도 R1 판 값이다 (D-70 · `규칙.md` §7). 원래 비어 있던 칸은 `(빈 칸)` 으로 적는다 |
| 고친 값 | 그 판본 작업본 셀의 값을 글자 그대로 |
| 도형 표 "전" · "후" | "전" 은 **원본(바탕)에서 그 도형 속성의 값** — 셀의 원래 값과 같이 어느 판본 절이든 같다 (G-2 · 바탕 없음이면 R1 판). 원본에 없던 도형은 `(없음)`. "후" 는 그 판본 작업본의 값이고, 지운 도형은 `(지움)` |
| 이 판 절에 싣는 줄 | **이 판에서 새로 바뀐 셀·도형만** — 직전 백업과 비교해 이 판에 바뀐 것 (G-10). 앞 판의 줄을 다시 싣지 않는다 |
| 원본으로 되돌린 셀 | 줄을 남긴다 — 고친 값 = 원래 값. 색 표시는 원래 채움으로 돌린다 |
| 근거 | 자료(파일·절·쪽·행) · 사용자 결정(일자 · 사용자 말) · 레이아웃 결정 번호. 검증 보고서 번호·★ 같은 파이프라인 낱말은 쓰지 않는다 (`규칙.md` §7) |
| 행·열 삽입/삭제 | "값 외 변경"에 먼저 적는다 — 그 아래 셀 주소가 밀린 것을 읽는 사람이 맞출 수 있게 |

- 수정 기록 파일 자체는 작업본 밖 파일이라 색 표시 대상이 아니다.
- 수정 기록을 작업본 안 시트로도 보여 달라는 사양이 있으면 그 시트는 레이아웃 결정으로 만들고, 기록의 원본은 이 파일로 둔다.
