# 참고자료 — 엑셀 도구와 함정 (엑셀작업 갈래)

> 알아야 할 것(지식)이다. 통째로 읽지 않고 필요한 절만 꺼내 본다. 따라 할 절차는 `skills/` 에, 지킬 것은 `규칙.md` 에 있다.
> 출처는 참고 사례 `03. 회로분석_TDSCU/log/` 의 구현요약·검증요약에 적힌 사실이다 — 줄마다 붙였다. (T6 = 블록도정리, T7 = 임피던스가이드, T9 = 아트웍대응, T10 = 테스트케이스)

## 1. 입력 특성 조사 · 값 읽기

| 무엇 | 어떻게 본다 | 함정 | 출처 |
|---|---|---|---|
| 도형·그림·차트·댓글 유무 | xlsx 는 zip 이다 — `zipfile` 로 부품 목록을 뽑는다: `xl/drawings/` · `xl/media/` · `xl/charts/` · `xl/comments*` · `xl/threadedComments/` · `xl/richData/` | openpyxl 로는 도형·스레드 댓글·셀 그림이 안 보이거나 다시 저장할 때 빠진다 | T10 A1_R1 M-1 |
| 데이터 유효성 · 조건부 서식 · 병합 · 인쇄 설정 · 정의된 이름 | 시트 XML 의 `dataValidations` · `conditionalFormatting` · `mergeCells` · `pageSetup`, `workbook.xml` 의 `definedNames` (openpyxl `merged_cells` · `page_setup` 도 읽기용으로 쓸 수 있다) | | T10 A1_R1 §11 · A1_R3 §10 |
| 수식과 계산 값 | 같은 파일을 `data_only=False`(수식) · `data_only=True`(마지막 저장 때의 계산 값)로 두 번 연다 | openpyxl 로 만든 파일은 계산 값이 비어 있다 (Excel 이 다시 계산해야 생긴다) | T7 B2_R1 T7-1 |
| 숫자처럼 보이는 글자 | 넣을 때 글자로 넣는다 (예: 일련번호 `0012`) — 숫자로 넣으면 앞 0 이 사라지고 표시가 바뀐다 | | T10 M-18 |
| 빈 칸 | `None`(빈 칸)과 `''`(빈 문자열)을 구별해 센다. 자료가 없는 칸은 비워 두지 않고 정한 미확인 표기 하나로 채운다 — 빈칸은 빠뜨림과 구별되지 않는다 | | T7 B2_R1 X-1 · T9 B2_R1 T9-13 |

| 같은 이름의 다른 판 | 파일 이름 · Rev · 날짜가 같아도 내용이 다를 수 있다 — SHA-256 · 파일 시각 · `docProps/core.xml` 로만 갈린 일이 있었다 | 판이 섞인 자료로 쓴 값은 시트마다 판 라벨이 달라진다 | T10 검증기준 · T6 091 검증요약 |

## 2. Excel COM (pywin32)

| 요령 | 까닭 · 사례 | 출처 |
|---|---|---|
| `win32com.client.DispatchEx("Excel.Application")` 로 **새 인스턴스**를 띄우고 `Visible=False` · `DisplayAlerts=False` | `Dispatch` · `GetActiveObject` 는 떠 있는 사용자 Excel 에 붙을 수 있다 | T6 A4 · A6_2차 · A7 |
| 끝나면 스크립트가 자기 통합문서를 `Close` 하고 자기 인스턴스를 `Quit` 한 뒤, EXCEL.EXE 목록을 다시 떠서 남은 것이 없는지 본다 | `Quit` 뒤에도 프로세스가 몇 초 남거나(T6 A1), 아예 남은 일이 있었다(T6 A3 · A5). 자기 프로세스를 끝내는 명령이 권한 판정에서 거부된 일도 있다(T6 A3 · A6) — 그때는 우회하지 않고 남은 PID 를 적어 돌려준다 | T6 A1 · A3 · A5 · A6 |
| **한 번에 하나**, 앞에서(foreground) 돌린다 | 백그라운드로 돌린 것을 멈추지 못해 세 벌이 겹쳐 돌고 인스턴스가 남았다 | T6 A6 |
| 사용자 Excel 의 자식 인스턴스(`/Embedding` 으로 뜬 것)를 자기 것으로 착각하지 않는다 — 실행 전에 떠 있던 PID 는 전부 사용자 것으로 본다 | | T6 A3 |
| 스크립트 첫 줄에서 `pythoncom` 을 먼저 import 한다 | 다른 모듈(pymupdf)을 먼저 import 하자 COM 속성 읽기가 실패했다 | T6 A6_2차 |
| 백업은 닫힌 파일이면 파일 복사, 열어 둔 통합문서면 `SaveCopyAs` | 같은 이름 백업이 있으면 멈춘다 | T6 A3 · A6_2차 |
| 저장하면 Excel 이 `printerSettings*.bin` 을 다시 쓰고 인쇄 배율 속성(`scale`)을 새로 만들 수 있다. 쪽 맞춤을 지키려면 `Zoom=100` 을 먼저 준 뒤 `Zoom=False` · `FitToPagesWide=1` · `FitToPagesTall=False` 순서로 준다 | `Zoom=False` 만으로는 `scale=39` 가 남았다 | T10 A1_R1 §12-1 · A1_R3 §9-2 |
| 색 값은 `R + G×256 + B×65536` (BGR 순) | | T6 A2 §7.2 |
| 글자 부분 서식은 `TextFrame.Characters(start, len).Font` | `TextFrame2.TextRange.Paragraphs(i)` 가 오류를 냈다 | T6 A2 §7.2 |
| 도형 조정값은 `Adjustments.SetItem(i, v)` | `Adjustments.Item[i] = v` 는 먹지 않았다 | T6 A2 §7.2 |
| 열어 둔 통합문서에 붙어야 하면 `GetObject(<전체 경로>)` 로 그 파일만 잡고 `FullName` · `Saved` · `ReadOnly` 를 먼저 출력한다. `Saved=False` 면 멈춘다 | 사용자가 고치던 내용을 섞어 저장하지 않게 | T6 A3 · A5 |
| 권한 판정은 **도형 삭제·생성**을 "되돌릴 수 없는 삭제"로 보고 거부한 일이 있다. 같은 결과를 속성 변경(위치·크기·글자)만으로 낼 수 있으면 레이아웃에서 그렇게 정한다 | 사용자가 Excel 을 닫은 뒤 새 인스턴스로 열어 적용하는 방식은 허용된 적이 있다 | T6 A2 · A3 M-A3-3 · A4 |

## 3. 도형(블록도) 다루기

| 요령 | 출처 |
|---|---|
| 편집은 COM 으로, 확인은 zip 안 `xl/drawings/drawingN.xml` 을 읽어서 한다 (앵커 셀 번호 + EMU 오프셋). openpyxl 로 저장하면 서식 있는 글이 지워진다 | T6 A3 · A6 |
| 도형 이름은 겹칠 수 있다 (대소문자만 다른 이름 · 같은 이름 여러 개) — 이름과 겹침 순서로 함께 찾는다 | T6 A3 · A5 |
| 기존 연결선이 도형에 붙지 않은 자유 직선일 수 있다 — `ConnectorFormat.BeginConnected` 로 먼저 확인한다 | T6 A2 · A5 |
| Excel 이 읽어 주는 좌표는 활성 시트·저장된 보기 배율에 따라 1~2.7 % 흔들린다 — 적용 뒤 비교는 좌표가 아니라 **앵커**로 한다. 도형은 `Placement=3`(셀과 따로 움직임) | T6 A3 · A4 · A5 |
| 배치는 고정값보다 **맨 위 변수 블록에서 계산**한다 — 블록도가 먼저 정해지고 구역이 그 크기를 따르게. 사용자가 고정 폭에 맞춘 배치를 네 차례 고쳐 달라고 한 끝에 이렇게 바뀌었다 | T6 A3 · A6_2차 M-A6-R2-10 |
| 글상자 높이가 모자라면 화면에서는 들어맞아도 PDF·인쇄에서 마지막 줄이 잘린다 — 줄 수 × 글자 크기에 넉넉한 줄 간격(약 2배)과 여백을 더해 잡는다 | T6 A2 · A6_2차 M-A6-R2-11 |
| 보기 배율은 사용자가 정한다 — 스크립트가 바꾸지 않는다 | T6 A3 M-A3-7 |
| 그림으로 확인하려면 **사본**을 새 인스턴스로 열어 `ExportAsFixedFormat` 으로 PDF 를 내보낸 뒤 이미지로 바꾼다. 작업본에서 하지 않는다 (인쇄 영역이 바뀐다) | T6 A2 · A6_2차 |
| 사용자가 수락한 앞 시트의 글자 크기·색·표제 꼴은 다음 시트에 그대로 이어 쓴다 (수락된 글자 위계 예: 최소 12 pt) | T6 A4 M-A4-2 · A6_2차 · A7 M-A7-4 |

## 4. 표 다루기

| 요령 | 출처 |
|---|---|
| 양식 채우기는 바탕 사본을 COM 으로 열어 **값과 채움만** 고친다. 행을 지우거나 끼우지 않고 문구로 처리하면 양식 끝 표지·서식이 지켜진다 | T10 A1_R1 · M-R2-3 |
| 회차마다 **바탕에서 처음부터 다시** 만들면 "바뀐 셀 = 색 표시 셀 = 기록"이 바탕 대비로 유지된다 | T10 A1_R2 M-R2-1 · A1_R3 M-R3-1 |
| 고친 행의 높이는 늘리기만 하고 줄이지 않는다 | T10 M-16 |
| 쓰지 않게 된 칸의 데이터 유효성은 그 칸만 범위에서 뺀다 (선택 목록이 남지 않게) | T10 A1_R3 M-R3-9 |
| 인쇄 반복 행이 다른 표 페이지에도 찍히면 헷갈린다 — 반복 행은 지키고 안내 문장을 둔다 | T10 B2_R1 X-3 · A1_R3 M-R3-8 |
| 신규 작성 표의 기본 꼴 예: 열 너비 지정 · `wrap_text` · 머리 행 틀 고정 · 자동 필터 · 인쇄 방향. 받는 사람용 시트에는 내부 기호·경로를 넣지 않는다 | T9 A1_R2 M-R2-7 · M-R2-12 |
| Excel 을 띄우지 않으면 화면 렌더(글자 잘림)는 직접 볼 수 없다 — 열 너비는 글자 수(전각 2 · 반각 1)로 어림한다는 사실을 구현요약에 적는다 | T9 A1_R2 §5-3 |

## 5. 표기가 흔들린 자리

| 사례 | 출처 |
|---|---|
| 같은 치수의 두 표기(`13 × 2 mm` / `13.0 × 2.0 mm`) — 한 표기로 맞추고 원문 인용은 그대로 둔다 | T9 B2_R1 · A1_R2 M-R2-3 |
| 같은 값에 표시 등급이 둘로 갈림 — 등급 규칙을 먼저 글로 정한다 | T9 A1_R2 M-R2-2 |
| 상태 낱말(열림 · 닫힘)을 먼저 정의하고 시트 표시와 맞춘다 — 열린 질문이 시트에 흔적 없이 남은 일이 있었다 | T10 A1_R1 M-4 · B2_R1 X-1 |
| 시트 사이 동의어(라벨) 혼용 · 하이픈과 대시 섞임 · 풀이 없는 약어 · 작업 흔적(EMU 값 · `%d`) | T6 A1 M-R2-19·20 · A4 · A5 |
| 회차가 지나 낡은 문구(반영 위치 등)가 남음 — 새 판마다 문구가 아직 사실인지 다시 본다 | T10 B2_R2 X-1 |
