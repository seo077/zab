# A 스킬 — 레이아웃/블록도

> 도형으로 뜻을 전하는 산출물의 **내용과 배치**를 정한다. 짝: 출력 스킬 `출력/블록도`.
> 문서의 꼴은 `../../참고자료/레이아웃_문서_양식.md`. 이 스킬은 그 양식 §6 결정 절에 블록도 작업이 더 정할 것과 차례를 준다. 지킬 것은 `../../규칙.md`. 도형 요령은 `../../참고자료/엑셀_도구와_함정.md` §2 · §3.
> 블록도 내용의 분야 사실(회로 노드 · 신호 이름이 맞는가)은 사양이 정한 근거 자료로만 정한다 — 근거 자료끼리 판이 다르면 고르지 말고 열린 질문으로.

## 적용 조건 — 출발점

| 출발점 | 이 스킬에서 달라지는 것 |
|---|---|
| 바탕 있음·편집 (기존 블록도를 고친다) | ④ 바탕 도형 실측 · ⑨ 도형 단위 변경 목록 을 한다 |
| 바탕 있음·양식 (표제·틀이 정해진 시트에 그린다) | ④ 에서 틀(표제 · 구역 · 인쇄 영역)을 재고, ⑦ 배치를 그 틀 안에서 정한다 |
| 바탕 없음 | ④ · ⑨ 는 "해당 없음 (바탕 없음)". 수정 기록 계획은 "R1 미적용 (D-59 G-4)" |

## 차례

① **착수 확인** — `규칙.md` §4 대로 잠금 · 실행 중 Excel 을 보고, 입력 전부의 SHA-256 · 크기를 양식 §2 에 적는다.
② **사본 만들기** — 입력을 자기 전용 임시 폴더로 복사해 사본만 읽는다.
③ **취향 파일 읽기** — `b/갈래별/엑셀작업/참고자료/사용자_취향.md` 에서 대상물 "블록도"와 이 Task 대상에 걸리는 줄을 찾는다 (`규칙.md` §8).
④ **바탕 도형 실측** (바탕 있음) — zip 안 `xl/drawings/drawingN.xml` 에서 시트마다 도형 수 · 이름 · id · 앵커(셀 + 오프셋) · 글자를 뽑는다. 이름이 겹치는 도형(대소문자만 다른 것 포함)은 이름 + 순서로 구별해 적는다. 연결선이 도형에 붙어 있는지(자유 직선인지)도 적는다. 보존 목록(양식 §7)과 특성 표(§4)를 채운다.
⑤ **읽고 분석하기** — 근거 자료에서 블록과 연결을 뽑는다. 읽은 범위를 양식 §3 에, 뽑은 결과를 §5 에.
⑥ **블록 · 연결 목록** — 블록마다 라벨 · 역할 · 근거. 연결마다 출발 → 도착 · 라벨(신호 이름) · 방향 · 근거. 바탕이 있으면 바탕 도형과 짝지어 적는다. 라벨 없는 블록을 두지 않는다.
⑦ **배치** — 출력 A 가 좌표를 추측하지 않게, 블록마다 위치·크기 또는 그것을 정하는 규칙(격자 · 흐름 방향 · 그룹 박스 범위 · 시트 안 영역)을 적는다. 고정 좌표보다 **변수로 계산되는 규칙**(블록도가 먼저 정해지고 구역이 그 크기를 따른다)을 먼저 고른다 (`엑셀_도구와_함정.md` §3).
⑧ **표기 규칙** — 색의 뜻과 범례 · 선 종류 · 화살표 방향 · 라벨 용어의 출처(용어집 · 근거 문서). 같은 기능군 블록은 같은 색·같은 글꼴. 라벨 · 글상자 글의 말투도 `../../규칙.md` §10 대로 여기서 정한다. 취향 파일 §3 줄이 걸리면 여기서 따른다.
⑨ **도형 단위 변경** (바탕 있음·편집) — 바꿀 도형마다 이름/id · 바꿀 속성(글자 · 위치 · 크기 · 색 · 선 · 연결 끝점) · 전 → 후 · 근거 · **표현을 바꾸는지 사실을 바꾸는지** 구분. 지울 도형 목록. 같은 결과를 속성 변경만으로 낼 수 있으면 삭제·생성보다 그쪽을 고른다 (`엑셀_도구와_함정.md` §2 — 권한 판정).
⑩ **가독성 제약** — 블록 겹침 금지(의도한 그룹 박스 제외) · 글자 넘침 방지(도형 크기 규칙 — 인쇄에서도 마지막 줄이 들어가게) · 라벨 가로 읽기 · 연결선을 도형 연결점에 붙일지 · 글자 크기 위계(최소 크기 포함).
⑪ **시트 나눔** (여러 시트) — 시트마다 다루는 범위 · 시트를 건너는 연결을 양쪽 시트에서 같은 이름으로 표시하는 방식 · 시트마다 표제(제목 · 판본 · 근거 판).
⑫ **도구** — 도형을 쓰는 작업은 COM 이다 (`규칙.md` §5). 그림으로 배치를 미리 보여야 하면 사본으로만 그려 본다 — 그린 그림은 레이아웃 문서에 경로로 붙인다.
⑬ **수정 기록 계획** — 도형은 색 표시 없이 기록 파일에만 적는다 (D-59 G-5). 셀을 함께 고치면 표시 색 RGB 도 정한다 (양식 §8).
⑭ **열린 질문 · 취향 반영 · 만족 조건** — 양식 §9 · §10 · §11.
⑮ **끝 확인** — 입력 SHA-256 을 다시 재서 ① 과 같은지, `output/` 에 아무것도 만들지 않았는지 본다. 그림 확인에 COM 을 썼으면 자기 인스턴스가 남지 않았는지 본다.

## 구현요약에 더 적을 것

- 쓴 스킬 경로 이름 (`레이아웃/블록도`) · 레이아웃 문서 경로와 SHA-256 · 입력 지문 (착수 · 끝)
- 착수 확인 결과 (잠금 · EXCEL.EXE PID — 실행 전후)
- 도형 실측에 쓴 스크립트의 핵심 조건 · 미리 그려 본 그림의 경로
