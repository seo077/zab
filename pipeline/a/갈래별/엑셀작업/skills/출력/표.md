# A 스킬 — 출력/표

> 승인된 레이아웃(`레이아웃/표` 로 쓴 결정)을 실제 xlsx 로 만든다. 짝: 레이아웃 스킬 `레이아웃/표`.
> 지킬 것은 `../../규칙.md` (특히 §3 안전 · §4 착수 전 확인 · §7 수정 기록). 수정 기록의 꼴은 `../../참고자료/수정기록_양식.md`. 도구 요령은 `../../참고자료/엑셀_도구와_함정.md` §2 · §4.
> 이 스킬의 차례 ① ~ ③ · ⑤ · ⑥ · ⑦ · ⑪ 은 `출력/블록도` 가 빌려 쓴다 (빌린 쪽이 차례 번호를 밝힌다).

## 적용 조건 — 출발점 (승인된 레이아웃 §1 이 정한 것)

| 출발점 | 이 스킬에서 달라지는 것 |
|---|---|
| 바탕 있음·편집 · 바탕 있음·양식 | 바탕을 `output/` 으로 복사해 출발. ⑤ 백업 · ⑦ 색 표시 · ⑨ 수정 기록을 한다. 양식이면 레이아웃의 비워 둘 칸 목록을 건드리지 않는다 |
| 바탕 없음 · 첫 판(R1) | 근거 자료에서 새로 만든다. 백업 · 색 표시 · 수정 기록은 하지 않는다 (D-59 G-4) — 구현요약에 "R1 미적용"이라 적는다 |
| 바탕 없음 · R2 이후 | 직전 판(지금 작업본)에서 이어 하고 백업도 그 판에서 뜬다. 수정 기록의 원래 값과 색 표시의 원본은 **R1 판**이다 — R3 이후에도 (`../../규칙.md` §7). 그 밖은 바탕 있음·편집과 같이 한다 |

## 차례

① **승인 지문 확인** — `log/T{N}_<작업명>/설계명세.md` 의 SHA-256 을 재서 호출문이 준 승인 값과 같은지 본다. 다르면 여기서 멈춘다.
② **착수 확인** — `규칙.md` §4 (잠금 · EXCEL.EXE PID · 작업본 지문). 입력 전부의 SHA-256 을 재서 레이아웃 문서 §2 값과 같은지 본다 — 다르면 멈춘다.
③ **작업본 자리** — 레이아웃 §1 의 작업본 경로. 바탕이 있으면 바탕을 그 자리로 복사하고 SHA-256 이 바탕과 같은지 본다. 이미 작업본이 있으면(R2 이후) 지우지 않고 그대로 둔다.
④ **dry** — 레이아웃 §6 결정(L-번호)마다 바뀔 것을 시트 · 셀 · 전 값 · 후 값 목록으로 뽑는다 (아직 쓰지 않는다). 목록을 `../../규칙.md` §3 의 dry 목록 파일(`<작업본 이름>_dry_<단계>.md`)로 남기고 줄 수를 센다. 레이아웃이 정하지 않아 추측해야 하는 자리가 나오면: 서식 세부면 정하고 M-N 으로, 내용·구조면 멈춘다 (`규칙.md` §6).
⑤ **백업** — 쓰기 직전에 `<작업본 이름>.pre<단계>.bak` 을 만들고 SHA-256 이 지금 작업본과 같은지 본다. 같은 이름이 있으면 멈춘다. ② 의 잠금 · Excel 확인을 **이때 한 번 더** 한다.
⑥ **apply** — 레이아웃이 정한 도구로 쓴다.
   - openpyxl: 작업본을 열어 값·서식을 쓰고 저장한다. 바탕에 도형·댓글·그림·데이터 유효성이 있는 파일이면 openpyxl 로 저장하지 않는다 (레이아웃이 COM 을 정했을 것이다 — 아니면 멈춘다).
   - COM: `DispatchEx` 새 인스턴스 · `Visible=False` · `DisplayAlerts=False` 로 작업본만 열어 값·채움을 쓰고 저장 · 닫기 · 자기 인스턴스 `Quit`. 쪽 맞춤 인쇄 설정이 있으면 `엑셀_도구와_함정.md` §2 의 순서로 다시 준다.
   - 다 쓴 뒤 실제 바뀐 것을 직전 백업(바탕 없음 첫 판이면 생략)과 셀 단위로 비교해 뽑고, ④ dry 목록과 대본다. 다른 줄과 그 까닭은 구현요약에 적는다 — dry 목록 파일은 고치지 않는다.
⑦ **색 표시** — 이 판에서 값이 바뀐 셀을 레이아웃 §8 의 표시 색으로 칠한다. 병합 셀은 왼쪽 위 칸. 원본 값으로 되돌린 셀은 원래 채움으로 돌린다. 레이아웃이 정한 서식 변경 말고 다른 채움색을 더하지 않는다.
⑧ **서식 · 받는 사람용 표기** — 레이아웃 §6 의 서식 결정(열 너비 · 줄바꿈 · 숫자 형식 · 머리 행 고정 · 인쇄)과 같은 역할 칸의 한 서식을 지킨다. 행 높이는 늘리기만 한다. 받는 사람에게 가는 시트에 내부 기호·경로를 넣지 않는다. 사람이 읽는 글(어휘 · 문장 · 말투)은 `../../규칙.md` §10 대로 쓴다.
⑨ **수정 기록** — `수정기록_양식.md` 대로 이번 판본 절을 덧붙인다. 셀 줄은 ⑥ 에서 뽑은 이 판 변경 집합 그대로, 원래 값은 **원본(바탕)** 셀 값.
⑩ **스스로 열어 보기** — 저장한 작업본을 openpyxl 로 다시 열어(예외 없음) 시트 수 · 시트마다 비어 있지 않은 셀 수를 세고, `zipfile.testzip()` 결과를 본다. 수식 셀이 있으면 계산 값이 비어 있는지 보고 비어 있으면 그 사실을 적는다. 바탕에 없던 `#REF!` 같은 오류값이 생기지 않았는지 문자열로 찾는다. 바탕이 있으면 보존 목록(레이아웃 §7)의 부품 수 · 병합 수 · 정의된 이름을 바탕과 다시 대본다.
⑪ **끝 확인** — 입력·바탕·레이아웃 문서 SHA-256 이 ① ② 와 같은지 · 산출 폴더에 `~$` · 임시 파일 · `__pycache__` 가 남지 않았는지 · 자기 Excel 인스턴스가 남지 않았는지(EXCEL.EXE 목록이 착수 때 PID 그대로인지).

## 구현요약에 더 적을 것

- 쓴 스킬 경로 이름 (`출력/표`) · 승인된 레이아웃 SHA-256 (① 에서 잰 값)
- 입력 지문 · 작업본 SHA-256 · 크기 · 백업 이름과 SHA-256 · 수정 기록 파일 경로
- 착수 확인과 apply 직전 확인 결과 · 권한 거부가 있었으면 그 사실과 처리 (없었으면 "없음")
- 쓴 도구와 실행 명령 · dry 목록 파일마다 경로와 SHA-256 · 줄 수와 실제 변경 수 · 다른 줄의 까닭 (`../../규칙.md` §3 — 목록 자체는 옮겨 싣지 않는다)
- 레이아웃과 다르게 한 곳 목록 (서식 세부 M-N) · 남은 확인 필요 목록
- 쓰기에 쓴 스크립트 전문 또는 핵심과 그 SHA-256 (임시 폴더는 세션이 끝나면 사라질 수 있다)
