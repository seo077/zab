# 규칙 — 회로분석 갈래

> 설계된 회로를 모듈별로 분석해 기능·동작·오류·위험을 진단할 때 A가 지킬 것.
> 갈래와 무관하게 늘 지키는 것은 `a/공통규칙.md`에 있다. 여기엔 **거기에 없는, 이 갈래에서만 필요한 것**만 적는다.
> 방법 세부(분해법·가설 양식·시뮬 절차·데이터시트 색인 형식)는 `참고자료/`에 있다 — 필요할 때만 꺼내 본다.

---

## 1. 시작 전에 판본을 못박는다

회로 3종(회로도 PDF · netlist · BOM)은 개정이 잦다. **분석을 시작하기 전에 어느 판을 기준으로 삼는지 지문으로 고정**하고, 통합·모듈별 문서 머리에 그대로 적는다.

- 지문 = **파일 경로 · 크기(byte) · 생성 시각 · SHA256**. 이후 회차는 이 판을 기준으로 삼는다.
- 판이 바뀌면 **바꿨다는 사실 + 새 지문 + 갈아치운 이유**를 남기고, 옛 판은 "기준에서 제외"로 표기하되 지우지 않는다.
- 판본 확정은 파이프라인 첫 ★(사용자 확인) 자리다 — 그 승인 전에는 분석을 확정하지 않는다.

---

### 1.1 형식과 판 전환 근거

착수 1단계에서 한 담당이 `output/분석/넷리스트형식.md`에 실제 원문/바이트 표본과 공백·탭·빈 선두/말미 필드·부품 값 경계, 패키지/핀 수, exporter 판·순서 출처, 자리↔핀 대응 근거·미확정을 기록한다. 문자열 정렬이나 몇 기준점/핀 수 일치를 전체 핀맵 확정으로 일반화하지 않는다. 필드는 `참고자료/06.넷리스트와_신호연결.md` §1에 있다.

입력·파서·핀맵이 바뀐 연결과 이전 미확인 연결은 다시 추적한다. 확인된 불변 연결 재사용에는 전후 입력 판/지문·양 끝/모든 분기·선택 모드 불변 근거·이전 확인 출처를 남긴다. 노드 번호가 남아 있다는 이유로 승계하지 않으며 불변 연결을 매번 수작업 전수 분석하도록 강제하지 않는다(같은 참고자료 §3).

## 2. 모듈로 나누고 한 번 준 이름은 안 바꾼다

회로 전체를 **기능 도메인**으로 쪼개 각각 독립 분석한다.

- 모듈 식별자 = `M#_기능코드` (예: `M2_PWR-CONV`, `M5_COMM-485`). **작업 종류가 아니라 그 회로의 기능**으로 짓는다.
- **한 번 부여한 모듈 번호·코드는 회차가 돌아도 재배치하지 않는다.** 추적성이 깨진다. (공통규칙 §3 자체 결정 번호 규칙과 같은 취지 — 여기선 모듈·가설·질의·가정 ID 전부에 적용)
- 모듈마다 **분석 깊이 L1/L2/L3**를 명시한다. 깊이 정의와 배정 기준은 `참고자료/01.모듈분해와_깊이.md`.

---

## 3. 세 자료를 서로 대조해서 읽는다 (한 자료만 믿지 않는다)

회로 사실은 **netlist·도면·BOM 세 자료의 교차검증**으로만 확정한다. 하나만 보고 단정하지 않는다.

- 노드·핀 이름은 **netlist 식별자에 맞춘다** — 나중에 시뮬 신호와 1:1로 맞대볼 수 있어야 한다.
- 세 자료가 어긋나면 그 자체가 발견거리다(미실장·표기 불일치·연결 누락 등). 어느 쪽이 맞다고 **A가 판정하지 않는다** — 사실만 나란히 적는다.
- 자료를 훑다 나온 "왜 이렇게 설계했나"는 추측으로 채우지 말고 **설계 의도 질의(`DQ-ID`)**로 뽑아 사용자 ★ 응답 자리로 넘긴다. 질의 양식은 `참고자료/02.설계의도질의_양식.md`.

---

### 3.1 신호의 양 끝·분기를 연결한다

전원/수동망과 신호망을 구분한다. 배정 신호마다 모든 끝점/분기의 소자·핀/볼, 입력 판의 원문 위치, 데이터시트 판·페이지·핀 기능, 가능한 다중화 기능과 선택 모드·출력 활성 조건·외부 구동·의도 출처를 모듈 문서의 “신호 연결”에 기록한다. TX/RX 등 이름은 보조 식별자로만 두고 방향 근거를 이름에서 채우지 않는다.

양방향·오픈드레인·3상태·외부 구동은 조건별로 구분한다. 출력 0개/복수는 확인 후보이며 모든 신호의 출력이 정확히 하나여야 한다는 법칙으로 쓰지 않는다. 미확정 핀/모드는 Q-ID로 남긴다. 각 깊이(L1/L2/L3)·제출 단계에서 허용하는 미확정 범위는 해당 Task 사양으로 정하고 기존 깊이를 모두 전수 분석으로 바꾸지 않는다. 표와 근거 연결은 `참고자료/06.넷리스트와_신호연결.md` §2를 쓴다.

## 4. 확보 못 한 값은 추정하지 말고 보류로 남긴다

데이터시트가 없거나 자체 발주 부품이라 정수를 모르면 **지어내지 않는다.**

- 추정·미확보 값은 전부 **`Q-ID`로 색인**하고, 쓴 자리 옆에 가정 출처를 병기한다. 형식은 `참고자료/03.데이터시트대조와_가정색인.md`.
- 데이터시트 확보 실패 = **`분석 보류` + `Q-ID`**. 그 항목은 심층 분석에서 빈칸으로 두되 왜 비었는지가 보이게 한다.
- `TBD`로 진행하기로 한 부품은 **추정 금지** — 사용자가 그렇게 정했으면 그대로 보류한다.
- 핀 대응·선택 모드·활성 조건이 불명이면 같은 Q-ID 방식으로 확인 못 한 사실·영향 신호/가설·시도/대체 수단·필요 결정을 남긴다. 후속표 등록은 현재 필요한 확인의 완료가 아니다. 담당·회차·중단/수락 결정은 Z·사용자에게 돌린다.

---

## 5. 가설은 세우되 판정하지 않는다

오류·위험 후보는 **가설 `H-N`**으로 누적한다. 가설을 세우고 그것을 가릴 측정/시뮬 매핑을 설계하는 데까지가 A 몫이다.

- 가설 표에는 **판정 낱말(`PASS`·`FAIL` 등)을 쓰지 않는다**(공통규칙 §2 G-5 보강 일관). 상태는 `잔여`·`후보`까지만. **기각/확정 판정은 검증자 단독**이다.
- 한 번 부여한 `H-N` 번호는 재사용·재배치하지 않는다. 기각돼도 지우지 말고 취소선 + 근거를 남긴다(공통규칙 §4 회차 보존 일관).
- 가설 양식·필드는 `참고자료/04.가설_H-N_양식.md`.

---

## 6. 시뮬은 A가 안 돌린다 — 준비하고 넘긴다

정량 동작은 추론만으로 확정하지 않는다. 다만 **시뮬 실행은 사용자가 수동으로** 한다(자동 시뮬 도구 없음).

- A가 하는 것: 기존 4단계에서 `output/모델/<모듈명>_시뮬사양.md`에 **기대 동작점 + 자극(stimulus) + 해석 설정 + 관찰점(netlist 노드명) + 모델 출처/가정 Q-ID + H-N 연결**을 사용자가 그대로 돌릴 수 있게 준비하고 사양 판·지문을 연결한다.
- 사용자가 하는 것: OrCAD/LTspice로 실행 → 같은 사양 판의 결과·파형·로그를 `output/시뮬/`의 회차/항목별 경로에 적재(★ 시뮬 결과 회수).
- 추론과 시뮬이 어긋나도 **"분석이 틀렸다"고 단정하지 않는다** — 범인이 분석인지 모델인지 자극인지 먼저 가린다. 절차는 `참고자료/05.시뮬_준비와_대조.md`. **대조·판정은 검증자 단독.** 5단계와 B에게 준비 사양(`output/모델/`)과 사용자 결과(`output/시뮬/`) 양쪽의 판·경로를 넘긴다.

---

## 7. 출력은 4계층으로 낸다

이 갈래의 산출물은 **네 벌**이다. 파일명에 **프로젝트명**을 넣어 파일 이름만으로 어느 회로인지 알게 한다.

| 계층 | 파일명 | 무엇 |
|---|---|---|
| 통합 분석 | `회로분석_<프로젝트명>.md` | 모듈 인덱스 + `H-N` 종합 + `Q-ID` 종합 + 커버리지 |
| 모듈별 분석 | `회로분석_<프로젝트명>_<모듈명>.md` | 모듈 하나의 노드 매핑·신호 흐름·정량 |
| 설계오류목록 | `설계오류목록_<프로젝트명>.md` | 사용자 확인 오류 / 잔여 가설을 **절을 갈라** 정리 |
| 데이터시트 색인 | `회로분석_<프로젝트명>_데이터시트색인.md` | 부품↔데이터시트↔가정(`Q-ID`) 대응 |

- **사용자 확인 오류**와 **미판정 잔여 가설**은 한 문서 안에서도 **절을 갈라** 섞지 않는다 — 앞은 사실 인용, 뒤는 아직 판정 전이다.
- 4계층은 서로 참조로 엮되, **같은 내용을 두 곳에 본문으로 중복하지 않는다.** 한 곳을 단일 출처로 두고 나머지는 가리킨다.

## 8. 참고자료 지도

`참고자료/`는 통째로 읽지 않는다. 그 단계에서 필요한 것만 연다.

| 파일 | 언제 |
|---|---|
| `01.모듈분해와_깊이.md` | step 1 — 모듈 나누고 L1/L2/L3 정할 때 |
| `02.설계의도질의_양식.md` | step 2 — `DQ-ID` 질의 뽑을 때 |
| `03.데이터시트대조와_가정색인.md` | step 3 — 데이터시트 대조·`Q-ID` 색인할 때 |
| `04.가설_H-N_양식.md` | step 4 — 오류·가설 도출할 때 |
| `05.시뮬_준비와_대조.md` | step 3~5 — 정량 동작점·시뮬 준비할 때 |
| `06.넷리스트와_신호연결.md` | step 1~3·판 전환 — 형식 관찰, 양 끝/분기·핀 기능/모드 근거, 재추적/재사용 기록 |
