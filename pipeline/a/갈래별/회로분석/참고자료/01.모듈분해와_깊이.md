# 모듈 분해와 분석 깊이 (L1/L2/L3)

> 회로 전체를 기능 도메인으로 쪼개는 법 + 모듈마다 얼마나 깊이 파는지 정하는 법.
> 규칙은 `../규칙.md` §2. 여기는 그 방법 세부다.

---

## 1. 기능 도메인으로 나눈다

회로를 **기능 단위**로 쪼개 각각 독립 분석한다. 어떤 회로든 반복되는 표준 축은 대략 이렇다(대상 회로에 맞게 가감).

| 도메인(예) | 포함 범위 | 대표 분석 포인트 |
|---|---|---|
| 전원 | 정류·평활·레귤레이터·기준전압·감시 | DC 동작점·리플·dropout·임계전압 |
| 클록·리셋 | 발진기·크리스털·POR·리셋 | 주파수 정확도·부하용량·리셋 타이밍 |
| 코어·로직 | MCU/FPGA·디커플링·디버그(JTAG) | 전원 분배·클록 트리·IO 레벨 |
| 통신 | 직렬(485/USB)·이더넷·격리 IF | 종단·정합·격리 전압·풀업 |
| IO·기구 | 스위치·LED·커넥터·계전기 IF | 결선·풀업/풀다운·미실장 |

- 모듈 식별자 = `M#_기능코드`. **한 번 주면 재배치 금지**(`../규칙.md` §2).
- 모듈 경계에 걸치는 신호(전원 레일·클록·리셋)는 **횡단축**으로 따로 묶어 모듈 간 단면을 본다.

## 2. 분석 깊이 L1/L2/L3

모듈마다 얼마나 깊이 파는지 명시한다. 전부 L3로 파면 비용이 폭발한다 — 의심 가는 데만 깊게.

| 깊이 | 정의 | 산출 수준 |
|---|---|---|
| L1 | 개념 수준 | 블록 역할·신호 흐름 정성 기술. 정량값 없음 |
| L2 | 동작 원리 | 동작 메커니즘 + 주요 노드 식별 (정량 일부) |
| L3 | 정량 동작 모델 | 정량 동작점 표 + 부품 정수 인용 + 시뮬 매핑 + 가정 명시 |

- **오류·고장 의심 모듈 = L3 권장**(정량 없이는 시뮬 대조 불가). 주변 모듈은 L1~L2로 아낀다.
- 한 모듈 안에서도 일부 블록만 L3로 올릴 수 있다(예: 클록·리셋 블록만 부분 L3).

## 3. 정량 동작점 표 (L3 필수 양식)

L3 모듈에는 **측정·시뮬로 확인 가능한 형태**의 동작점 표를 둔다.

| 노드/신호 | 정상값(typ) | 한계/마진 | 출처·가정 |
|---|---|---|---|
| `<노드명 (netlist 식별자)>` | `<전압/전류/주파수>` | `<상·하한 또는 마진>` | `<계산 근거 + 가정 Q-ID>` |

- 노드명은 **netlist 식별자와 일치**시킨다(시뮬 신호와 1:1 대조).
- 추정값이면 **반드시 가정 출처(`Q-ID`)를 병기**한다.

## 4. step 1 산출물

- 모듈분해표(`output/분석/모듈분해표.md`) = 모듈 목록 + 각 모듈의 기능·도면 시트·깊이 배정 + 횡단축.
- 이 표가 이후 모듈별 분석 문서들의 뼈대가 된다.
