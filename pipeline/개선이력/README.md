# 개선이력

파이프라인 저장소를 **왜 · 어떻게 고쳤는지** 남기는 곳.

## 무엇을 남기나

되풀이해서 쓸모가 확인된 교훈만 남긴다. 한 번 겪은 일은 프로젝트 쪽 로그에 두고, **두 번 겪으면** 여기로 올린다.
올라오는 방향은 한쪽뿐이다 — 프로젝트 → 파이프라인. 반대로 내려보내지 않는다.

## 언제 쓰나

작업 **도중에는 쓰지 않는다.** 작업 중 `pipeline/` 아래는 읽기 전용이다.
작업 도중 발견한 것은 메모로 들고 있다가, 작업이 끝난 뒤 별도 회차에서 여기에 정리한다.

## 파일 이름

```
NNN_<한 줄 제목>.md      예: 001_서브에이전트가_사용자_승인을_건너뛴_건.md
```

## 한 건에 담을 것

| 항목 | 내용 |
|---|---|
| 날짜 | 언제 겪었나 |
| 어디서 | 어느 프로젝트 · 어느 파이프라인 · 어느 단계 |
| 무슨 일이 있었나 | 사실만. 짧게 |
| 왜 그랬나 | 짐작이면 짐작이라고 적는다 |
| 무엇을 고쳤나 | 어느 파일의 무엇을 어떻게 |
| 다시 겪으면 | 같은 일이 또 나면 무엇을 볼지 |
