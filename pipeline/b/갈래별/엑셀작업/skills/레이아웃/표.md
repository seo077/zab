> 종류: 지시문 · 언제: 엑셀작업 Task 의 **레이아웃 B** 가 대상물 "표"의 레이아웃 문서(`log/T{N}_<작업명>/설계명세.md`)를 판정할 때 — 이 파일은 **레이아웃 기준 B** 가 열어 합본 `검증기준_레이아웃.md` 의 판독 방법 구획에 옮겨 싣고, 레이아웃 B 는 판정 때 이 파일을 열지 않고 합본에 옮겨진 것을 읽는다 (`b/공통규칙.md` §9.3) · 도구: 셸(`sha256sum`·`ls -la`·`find`) · Python(`py -3 -I`) + openpyxl · `zipfile`

# B 스킬 — 레이아웃/표

> **방법만 담는다.** 무엇을 볼지(항목·심각도)는 Task 방의 승인된 합본(`검증기준.md` 목차 + `검증기준_레이아웃.md` — 갈래 기준 §7 ①)에만 있다 — 갈래 원천은 `b/갈래별/엑셀작업/검증기준.md` §4.1 LC · §4.2 LT. 이 파일과 항목이 어긋나 보이면 **승인된 기준이 이긴다.**
> 짝: A 쪽 `a/갈래별/엑셀작업/skills/레이아웃/표` (끝 모양 — 파일 `.md` / 폴더 — 은 A 규약 `a/공통규칙.md` §7.2 대로. 경로 이름 `레이아웃/표` 이 한 글자라도 다르면 결과에 적는다).
> 판독 함정은 `b/갈래별/엑셀작업/참고자료/엑셀_판독_함정.md` §1, 판독 규율은 같은 파일 §2.

## 1. 준비

1. 산출 폴더·입력 폴더에 `~$` 잠금이 있는지 `ls -la` — 있으면 시작하지 않고 돌려준다.
2. 레이아웃 문서와 입력 전부(원본·바탕 xlsx · 근거 자료)를 **scratchpad 아래 내 하위 폴더**로 복사하고 원본·사본 SHA-256 이 같은지 확인한다. A 가 남긴 스크립트·중간 파일은 열지 않는다.
3. **레이아웃 문서의 SHA-256 을 보고서 머리에 적는다** — ★ 설계 승인 뒤 출력 기준 B 가 이 값과 승인본을 대어 출력 합본에 승인 시점 값으로 박고(갈래 기준 §7 ⑤ ⓐ), 출력 B 는 그 값으로 OC-2 를 본다.

## 2. 판독 절차 (항목 순서대로)

| 차례 | 하는 일 | 항목 |
|---|---|---|
| ① | 입력 전부 SHA-256 재계산 → 문서 기재값과 비교. 다르면 **멈추고 알린다** | LC-1 |
| ② | 문서에서 스킬 이름 · 출발점 · 바탕 · 작업본 경로 · 판본을 찾는다 | LC-2 |
| ③ | 입력을 openpyxl 로 열어 시트 목록 · 숨김 상태(`sheet_state` · 행/열 `hidden`) · `auto_filter.ref` · `merged_cells` · 메모를, `zipfile` 로 drawing·threadedComments 부품을 뽑아 문서의 "읽은 범위"와 대조 | LC-3 · LC-6 |
| ④ | 문서의 개수·합계·목록을 **내 스크립트**로 다시 계산 (A 스크립트 쓰지 않음) | LC-4 |
| ⑤ | 근거 인용 무작위 10건 이상 + 결론을 좌우하는 인용 전건을 입력 사본에서 연다 | LC-5 · LC-7 |
| ⑥ | 입력 특성(부품 목록·유효성·수식) ↔ 문서의 도구 결정 | LC-8 |
| ⑦ | [바탕] 보존 목록 실측 — 부품 목록 · 시트별 `merged_cells` 수 · `defined_names` · `page_setup`·`print_area`·`print_title_rows` · `data_validations` · 조건부 서식 · 채움색 분포(rgb·theme 따로) → 문서 목록과 양방향 대조. 고른 표시 색이 바탕 채움색과 겹치지 않는지 | LC-9 · LC-11 |
| ⑧ | 시트 목록(LT-1) · 열 표(LT-2) · 모집단(LT-3 — 근거 자료에서 내가 직접 뽑아 차집합) · 근거 규칙(LT-4) · 양식 틀·비워 둘 칸(LT-5 — 바탕에서 재서 대조) · 병합 계획(LT-6 — 범위 안 비어 있지 않은 칸을 바탕에서 뽑아 처리 유무 대조) | LT-1~6 |
| ⑨ | **출력 A 가 되어** 시트마다 결정 최소 3건 + 사양이 지목한 결정 전수를 셀 주소까지 따라가 본다. 추측이 필요한 자리를 적는다 | LC-10 · 공통 C-F2 |
| ⑩ | 결정 목록 ↔ Task 사양·사용자 답 귀속표 | LC-12 |
| ⑪ | 서식 · 받는 사람 가독성 계획 | LT-7 · LT-8 |
