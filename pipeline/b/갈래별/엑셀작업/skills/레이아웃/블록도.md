# B 스킬 — 레이아웃/블록도

> **방법만 담는다.** 항목·심각도는 Task 방의 승인된 합본(`검증기준.md` 목차 + `검증기준_레이아웃.md` — 갈래 기준 §7 ①)에만 있다 — 갈래 원천은 `b/갈래별/엑셀작업/검증기준.md` §4.1 LC · §4.3 LB. 어긋나 보이면 **승인된 기준이 이긴다.**
> 짝: A 쪽 `a/갈래별/엑셀작업/skills/레이아웃/블록도` (끝 모양 — 파일 `.md` / 폴더 — 은 A 규약 `a/공통규칙.md` §7.2 대로. 경로 이름 `레이아웃/블록도` 이 한 글자라도 다르면 결과에 적는다).
> 판독 함정은 `b/갈래별/엑셀작업/참고자료/엑셀_판독_함정.md` §1 (특히 "Excel 재저장 재직렬화"), 판독 규율은 같은 파일 §2.

## 1. 준비

1. `~$` 잠금 확인 (있으면 시작하지 않는다).
2. 레이아웃 문서·입력을 scratchpad 내 하위 폴더로 복사, 사본 SHA-256 = 원본 확인.
3. **레이아웃 문서의 SHA-256 을 보고서 머리에 적는다** — ★ 설계 승인 뒤 출력 기준 B 가 이 값과 승인본을 대어 출력 합본에 승인 시점 값으로 박고(갈래 기준 §7 ⑤ ⓐ), 출력 B 는 그 값으로 OC-2 를 본다.
4. [바탕]이면 바탕 xlsx 사본을 zip 으로 풀어 `xl/drawings/drawingN.xml` · `xl/drawings/_rels/` · `xl/worksheets/_rels/` · `xl/media/` 를 확보하고, 시트 ↔ drawing 대응을 rels 로 맞춰 둔다.
