# B 스킬 — 출력/표

> **방법만 담는다.** 항목·심각도는 Task 방의 승인된 합본(`검증기준.md` 목차 + `검증기준_출력.md` — 갈래 기준 §7 ①)에만 있다 — 갈래 원천은 `b/갈래별/엑셀작업/검증기준.md` §5.1 OC · §5.2 OT. 어긋나 보이면 **승인된 기준이 이긴다.**
> **잣대는 승인된 레이아웃 문서다.** 레이아웃이 옳은지 다시 판정하지 않는다 — 레이아웃 결함이 보이면 따로 적는다 (갈래 기준 §9).

## 1. 준비

0. **기준 승인 방식 확인** — `검증기준_출력.md` 머리표의 "승인 방식"(★ 출력 기준 승인 받음 / 생략)을 장부 확인지점과 대본다. 생략이면 ★ 레이아웃 기준 승인 자리의 생략 결정을 보고서 "근거로 쓴 기준" 줄에 적는다 (갈래 기준 §7 ①). 장부와 머리표가 어긋나면 멈추고 알린다.
1. 산출·입력 폴더 `~$` 잠금 확인 (있으면 시작하지 않는다). 떠 있는 Excel 이 있으면 PID 만 적는다.
2. **입력 전부 + 레이아웃 문서(`설계명세.md`) SHA-256 재계산** → 입력은 레이아웃 기재값, 레이아웃은 **출력 합본(`검증기준_출력.md`)에 적힌 승인 시점 값**과 비교. 다르면 **멈추고 알린다** (OC-2).
3. 바탕 · 백업 전부 · 작업본 · 수정 기록 파일 · **dry 목록 파일 전부**(작업본과 같은 폴더 — 구현요약에 경로가 있다, ⑬)를 scratchpad 내 하위 폴더로 복사, 사본 지문 확인. A 의 빌드 스크립트는 실행하지 않는다. **원본** = 바탕이다 — 바탕 없이 새로 만든 작업본(갈래 기준 §3.3 [신규])의 R2 이후에는 **R1 판**(R2 첫 단계의 편집 직전 백업)이 원본이고 R3 이후에도 같다 (D-70). 아래 ③ ④ ⑤ 의 "원본"은 이 파일이다.
