## 1. 값을 잘못 세기 쉬운 자리

| 함정 | 무엇이 일어나나 | 어떻게 피하나 | 관련 항목 | 출처 |
|---|---|---|---|---|
| **수식 캐시 값** | openpyxl 로 저장한 파일은 수식의 계산 결과(캐시)가 비어 있다. `data_only=True` 로 읽으면 `None` 이 나온다 | 수식 셀 목록을 따로 뽑고, 수식과 캐시 값을 둘 다 본다 | OC-12 · LC-6 | T7-1 · T9-27 |
| **빈 문자열 `''` 와 빈 칸 `None`** | 새로 쓴 칸에 `''` 가 들어가면 "값이 바뀐 셀" 수가 세는 법에 따라 갈린다 | diff 를 낼 때 두 방식으로 다 세어 차이 칸을 따로 적는다 | OC-14 · OT-5 | T10 B2_R1 X-4 · T10 B2_R2 T10-9 |
| **병합 셀의 값** | 병합 범위의 값은 왼쪽 위 칸에만 있다. 나머지 칸은 `MergedCell` 로 읽혀 값이 없다 | 병합 범위 단위로 읽는다. 새 병합 전 범위 안 다른 칸에 값이 있었는지 원본에서 확인 | LT-6 · OT-12 · LC-6 | T10 A1_R1 M-2 (병합 셀은 왼쪽 위만 칠함) · T10-5 |
| **스레드 댓글** | openpyxl 은 스레드 댓글을 레거시 메모로만 읽는다 ("[스레드 댓글] …"). 내용·답글 구조는 `xl/threadedComments/*.xml` 에 있다 | 부품 목록과 메모를 함께 본다. 내용 동일성까지 보려면 XML 을 직접 연다 | OC-8 · LC-3 · LC-6 | T10 검증기준 "못 본 것" · T10 B2_R1 §6 |
| **`scale` 과 `fitToPage`** | `fitToPage=True` 면 `scale` 값은 인쇄에 쓰이지 않는다. 값이 새로 생겨도 실효가 없을 수 있다 | 인쇄 설정은 `fitToPage`·`fitToWidth/Height` 와 함께 해석한다 | OT-3 · LT-5 | T10 B2_R1 X-3 |
| **인쇄 영역과 늘어난 행·열** | 행·열을 더해도 인쇄 영역은 자동으로 늘지 않는다. 새 열이 인쇄 영역 밖에 남는다 | `print_area` 끝 행·끝 열을 `max_row`·`max_column` 과 비교 | OT-3 · LT-5 | T10-7 · T10 S-4 (원본부터 G열이 영역 밖) |
| **같은 이름 다른 판** | 파일 이름·표지 판 표기·바닥글 날짜가 같은 두 판이 있을 수 있다 | 판 구별은 SHA-256 · 파일 시각 · `docProps/core.xml` 수정 시각으로 | LC-1 · OC-2 | T10 검증기준 §"한계" |
| **Excel 재저장 재직렬화** | Excel 로 다시 저장하면 뜻이 같아도 XML 속성 순서·id 가 바뀐다 | 도형은 id 대신 이름·텍스트·좌표로 짝짓고, 뜻이 같다고 본 근거를 적는다. 못 가린 범위는 못 본 것 | OB-1 · OC-17 | T6 P-6 · T6 §9 |
| **채움색 표기** | 같은 색이 theme 색과 rgb 로 다르게 저장될 수 있다. 원본 바탕 채움은 theme 인 경우가 많다 | rgb 값과 theme 채움을 나눠 분포를 낸다 | OC-16 · LC-11 | T10 S-3 ("theme 채움 + `FFFFC000` 4칸") |

## 2. B 의 판독 규율 (방법 — 독립성·안전을 지키려고)

| 규율 | 왜 | 출처 |
|---|---|---|
| 작업본·입력은 **scratchpad 로 복사한 사본만** 읽는다 (사본 해시 = 원본 해시 확인) | 원본·작업본을 실수로 잠그거나 바꾸지 않으려고 | T10 B2_R1 §0 · T6 §8-4 |
| **Excel 을 띄우지 않는다.** 떠 있는 Excel 이 있으면 PID 만 적고 닫지 않는다 | 사용자 인스턴스 간섭 금지 · 파일 잠금 | T10 B2_R2 §0 · X-3 |
| 착수 전 산출 폴더에 `~$` 잠금이 있으면 **판정을 시작하지 않는다** | A 의 편집 세션이 끝나지 않았을 수 있다 | T6 §8-1 |
| A 의 빌드 스크립트를 **실행하지 않는다** | 출력 경로를 생략하면 지정 경로를 덮어쓴다 | T10 B2_R1 §6 · B2_R2 §6 |
| A 가 scratchpad 에 남긴 점검 스크립트·중간 결과를 **열지 않는다**. 자기 파일은 하위 폴더에 둔다 | 독립성 (I-2) — 모드2 에서 A·B 가 같은 임시 폴더를 쓸 수 있다 | T7 B2_R1 X-7 |
| 내 스크립트·추출본은 scratchpad 에 두고, 보고서에 이름과 결과 원문을 적는다 | 재현 가능하게 (P-5) | T10 B2_R1 §0 "도구" |
| 다른 검증자(B1·이전 B2)의 추출본·스크립트도 쓰지 않는다 | I-1 | T10 B2_R2 §0 |

## 3. 자주 쓴 판독 수단 (참고)

- **값·채움·병합·인쇄 설정·유효성**: Python(`py -3 -I`) + openpyxl — `ws.merged_cells.ranges` · `ws.page_setup` · `ws.print_area` · `ws.print_title_rows` · `ws.sheet_properties.pageSetUpPr.fitToPage` · `cell.fill.fgColor.rgb` · `ws.data_validations` (T10 B2 `meta.py`·`diff.py`·`form.py` 류)
- **도형·그림·댓글·외부 링크**: `zipfile` 로 부품 목록 · `xl/drawings/drawingN.xml` 의 `xdr:sp`·`xdr:cxnSp`(`stCxn`·`endCxn`)·`xdr:pic` · `xl/media/*` 해시 (T6 R1 보고서 "검증 도구·재현")
- **지문**: `sha256sum` · `ls -la --time-style=full-iso`
- **바뀐 파일**: `find <프로젝트> -newer <검증기준.md> -type f` (git 미추적 프로젝트에서 — 시각 보존 덮어쓰기는 못 잡는다)

> 단계 × 대상물별 판독 절차는 `skills/<단계>/<대상물>.md` (`레이아웃/표` · `레이아웃/블록도` · `출력/표` · `출력/블록도`) 에 있다 — 판정 B 는 그 파일들을 열지 않고, 기준 B 가 합본의 판독 방법 구획에 옮겨 실은 것을 읽는다 (`b/공통규칙.md` §9.3). 여기 §3 은 그 절차들이 함께 쓰는 수단의 목록이다 (D-59 G-9 · D-60 G-11 · `검증기준.md` §3). 표현·디자인·가독성(OC-20~24)의 패턴 목록은 같은 폴더 `표현_패턴_사전.md` 에 있다.
